# web-lamorada

Recursos y contenido para el sitio web del **Parque Cementerio "La Morada"** (Santa Cruz de la Sierra, Bolivia).

## Estructura

- `Contexto.md` — Instrucciones del proyecto: objetivo, público, tono de voz, estructura del sitio y lineamientos éticos.
- `contenido/Informacion.md` — Textos e información de la empresa (nosotros, misión, visión, beneficios, contacto).
- `imagenes/` — Logos, volantes y renders del parque.
  - `Logo_horizontal.png`, `Logo_vertical.png`
  - `Volante_2025_adelante.jpg`, `Volante_2025_atras.jpg`
  - `2222.jpeg`, `5.jpeg`, `z_3.jpeg`, `z_4.jpeg` — renders del parque
- `Prueba.md` — archivo inicial.
